
# Customer Support Ticket Tracker


## Live Demo

[View Customer Support Ticket Tracker](https://lilasia904.github.io/customer-support-tracker/)

## About the Project

A customer support ticket tracker built using HTML, CSS, and JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- localStorage


## Features

- Create and delete customer support tickets
- Save tickets using browser localStorage
- Update ticket statuses: Open, In Progress, and Resolved
- Automatically update dashboard statistics
- Filter tickets by status
- Search existing tickets by title
- Display a "No matching tickets found" message when no results match
- Responsive layout for desktop and mobile devices
